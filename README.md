# رزومه نیکان عظیمی 📄

سایت رزومه شخصی فارسی (راست‌چین) با **پایتون و Flask**.

## امکانات
- 🏠 خانه با افکت تایپینگ
- 👤 درباره من + مهارت‌ها + تایم‌لاین
- 💼 نمونه‌کارها با فیلتر + لینک گیت‌هاب
- 📩 فرم تماس با دیتابیس SQLite
- 🌙 حالت شب/روز + ریسپانسیو
- 🔌 API پروژه‌ها در `/api/projects`

## اجرا
```bash
pip install -r requirements.txt
python app.py
```
بعد برو به http://127.0.0.1:5000
